# История изменений

## 1.0.0 (2026-10-30)

- ID загрузчика NeoForge: `thaumicenergistics_aop`; namespace контента `thaumicenergistics`, существующие конфиги и обнаружение интеграций сохранены.

- Автоматическая сборка зависимостей AOP из исходников в CI с проверкой ревизий и хешей JAR, без ручных переменных архива.

- Первый упакованный релиз порта на Minecraft 1.21.1 на основе Thaumic Energistics 1.1.3.0/AE2 RV3. Сети эссенции, терминалы, арканная автоматизация и рюкзаки големов используют публичный API AOP.
- Minecraft 1.21.1, NeoForge 21.1.166, Java 21.
- Минимальная поддерживаемая NeoForge: 21.1.166. Интеграция AE2 собирается с 19.0.24.
