# Changelog

## 1.0.0 (2026-10-30)

- Use NeoForge loader ID `thaumicenergistics_aop` while retaining the `thaumicenergistics` content namespace, existing configs and integration detection.

- Build AOP CI dependencies from source automatically; verify source identities and JAR checksums without manual archive variables.

- First packaged Minecraft 1.21.1 port release, based on Thaumic Energistics 1.1.3.0/AE2 RV3. Essentia networks, terminals, arcane automation and golem backpacks use the public AOP APIs.
- Minecraft 1.21.1, NeoForge 21.1.166, Java 21.
- Minimum supported NeoForge: 21.1.166. AE2 integration builds against 19.0.24.
